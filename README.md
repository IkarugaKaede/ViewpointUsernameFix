# Viewpoint 中文用户名闪退修复

适用于 Project Zomboid Build 42 的 Viewpoint 模组。用于修复 Windows 用户名含中文等非英文字符时，加入世界后因字体加载失败而闪退的问题。

## 使用方法

1. 退出游戏和 Steam。
2. 下载本项目的 `mods` 文件夹。
3. 用其中的文件覆盖创意工坊 Viewpoint 模组目录：

   ```text
   <Steam库>\steamapps\workshop\content\108600\3809306528\mods
   ```

> 临时使用gpt修复中文用户名问题，仅在本人测试管用，不保证百分百有效

  创意工坊更新模组后可能覆盖此修复
  10.16日12:43viewpoint模组更新的热补丁可能导致替换失效，可重新替换.jar文件
